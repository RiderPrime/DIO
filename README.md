# Simulador de Investimentos em FIIs

## Objetivo

Ferramenta desenvolvida em Excel para simular a evolução de
investimentos mensais em fundos imobiliários.

## Perguntas respondidas

- Quanto investir por mês?
- Por quantos anos?
- Qual o rendimento mensal?
- Quanto patrimônio será acumulado?
- Quanto será recebido em dividendos?

## Fórmulas utilizadas

### VF

A função VF foi utilizada para calcular o patrimônio acumulado
a partir do aporte mensal, prazo e rendimento mensal.

### PROCV

O PROCV é utilizado para localizar o percentual correspondente
à combinação entre perfil de investidor e tipo de fundo.

## Intervalos nomeados

- aporte
- taxa_mensal
- prazo_anos
- salario
- ...

## Perfis

Os percentuais utilizados são parâmetros fictícios para fins
educacionais e não representam recomendação de investimento.
